STEAL THE RAINBOW is a 2D puzzle-platformer where the last unicorn can steal colours from the world and transfer them to other objects.

Each colour has a different power:

🔴 Red — heat / burn
🟠 Orange — force / move
🟡 Yellow — power machines
🟢 Green — grow bridges
🔵 Blue — freeze
🔷 Indigo — gravity
🟣 Violet — portals

You can carry only one colour at a time, so later puzzles require you to use a colour, cross an obstacle, steal it back, and reuse it somewhere else.

The game features 100 stages, ranging from short breather levels to long multi-step puzzle gauntlets. Difficulty intentionally rises and falls, with increasingly complex colour combinations toward the end.

Controls

A / D or Arrow Keys — Move
W / Space / Up — Jump
Click — Take / Give colour
Z — Undo colour transfer
R — Restart stage
Esc — Pause
M — Sound

Collect all 7 rainbow diamonds and reach the rainbow arch to complete each stage.

Everything — graphics, animation, levels and procedural audio — is contained inside the 13KB submission.
